# 네이버 실제 발행 컨트롤러 v3

기존 100KB server.js와 별개로 구현한 새 실행 경로입니다. 자동 시작 발행은 없으며 인증한 POST 요청만 처리합니다. 대상 블로그는 tlsehdduq0152로 제한됩니다.

## 현재 검증 범위

- 로컬 단위 테스트: 콘텐츠 검증, HTML 이스케이프, 표·굵게·형광펜 렌더링, 저장 복구, 동시 실행 방지, 발행 응답 유실 시 재발행 차단.
- **네이버 실제 편집기·발행 UI 검증은 미실시**. HTML 붙여넣기 처리, 사진 버튼, 전체공개 라디오, 태그 입력창은 실제 UI에서 교정해야 합니다. 이 과정이 실패하면 발행 성공으로 기록하지 않습니다.
- 게시물 URL, 제목, 본문 순서, 표 셀, 강조 스타일, 이미지 개수를 재열어 검사한 경우에만 PUBLISHED를 기록합니다. 이미지 내용·본문 내 위치·대체텍스트 입력 및 대표이미지/카테고리 지정은 아직 검증·구현되지 않았습니다. 현재 카테고리는 편집기 기본값을 사용합니다.
- 원고/이미지 자동 생성은 아직 연결되지 않았습니다. 예시는 비발행용 서식 확인 자료입니다. 세법 원고는 작성 시 공식 근거를 확인해야 합니다.
- 임시저장 모드는 현재 지원하지 않습니다. mode=publish를 사용합니다.

## Railway 구성

1. 새 서비스 또는 별도 브랜치에서 Root Directory를 `publish-v3`로 설정합니다. 기존 서비스는 유지합니다.
2. Node 22+, `npm install`, `npm start`. 인스턴스/replica는 **1개**입니다.
3. 영구 볼륨을 `/data`에 연결합니다. `DATA_DIR=/data`, `CDP_ENDPOINT=<내부 Chromium CDP 주소>`, `API_TOKEN=<32자 이상 기존 비밀 토큰>` 설정. 키나 쿠키를 저장소에 넣지 않습니다.
4. `/data/assets/`에 이미지 파일을 준비합니다. 요청의 image.file은 확장자 png/jpg/jpeg인 단순 파일명만 허용합니다.
5. Chromium은 별도 서비스의 로그인된 프로필을 사용합니다. 이 컨트롤러는 인증정보를 입력하거나 CAPTCHA를 풀지 않습니다. 로그인 필요 시 작업을 중단합니다.
6. GET `/health`를 헬스체크로 사용합니다. POST `/jobs` 및 GET `/jobs/<id>`는 `Authorization: Bearer ...`가 필요합니다.
7. 검토할 원고와 이미지를 준비하고 편집기 서식 검증을 마친 후 실제 발행 요청을 연결합니다. 예제 요청을 production으로 보내지 마세요.

## 상태와 재시도

EDITING → PUBLISHING → VERIFYING → PUBLISHED. 오류는 FAILED 또는 NEEDS_RECONCILIATION입니다. 발행 클릭 전 PUBLISHING을 fsync하여 기록합니다. 동일 ID 재요청은 완료 결과를 반환하거나 조정 필요 오류를 반환합니다. 실패 글도 자동 재입력하지 않습니다.

프로세스가 강제 종료되면 `.worker-lock`이 남아 실행을 차단합니다. 작업이 실제로 종료됐는지, 해당 글이 이미 게시됐는지 확인한 뒤 운영자가 잠금을 정리해야 합니다. PUBLISHING/VERIFYING 작업은 기존 글 URL·내용을 먼저 확인하고 상태를 수동 조정해야 합니다. 미확인 상태에서 새 ID로 재발행하지 마세요. 자동 복구/관리 API는 아직 없습니다.

파일 스토어는 단일 프로세스·로컬 영구 볼륨용입니다. 다중 replica나 공유 네트워크 파일시스템용이 아닙니다. `202 ACCEPTED`는 발행 완료가 아니므로 상태 조회에서 PUBLISHED와 url을 확인해야 합니다.

## 요청 형식

```json
{
  "id": "unique-content-id",
  "blog": "tlsehdduq0152",
  "mode": "publish",
  "title": "검토를 마친 실제 원고 제목",
  "blocks": [
    {"type":"heading","runs":[{"text":"핵심 확인사항","bold":true}]},
    {"type":"paragraph","runs":[{"text":"강조할 문장","bold":true,"highlight":true}]},
    {"type":"table","rows":[["구분","확인사항"],["증빙","계약서와 결제내역"]]},
    {"type":"image","file":"content-01.png","alt":"설명 이미지"}
  ]
}
```

이미지는 제공된 예시의 3:2, 966×644, 연녹색·크림색, 진녹색 한글 제목, 인물 설명형/3칸 비교형을 제작 기준으로 합니다. 현재 adapter는 alt 값을 사진에 입력하지 않으며 이미지 생성·규격 검사는 별도 후속 단계입니다.
