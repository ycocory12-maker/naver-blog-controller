## P0 수정 설계 (코드 반영 전 승인 및 리뷰 필수)

1. **출구를 먼저 막는 fail-closed 가드**: 모든 자동 스케줄/큐 처리 경로에서 `publish_mode !== 'draft_only'`이면 작업을 거부하고, `saveDraft` 구현 및 재열기 검증이 없으면 작업을 `BLOCKED_DRAFT_NOT_IMPLEMENTED`로 종료. 절대로 `publishDue` 또는 발행 버튼 경로로 폴백하지 않음.
2. **승인 후 발행 예약 비활성화**: 운영 `naver-daily-publish` cron과 `naver-publisher-v3`의 내부 스케줄러 활성 상태를 각각 읽기 전용으로 확인하고, 안전한 순서로 정지/격리. 운영 설정 변경은 사용자 승인 후만.
3. **중복 방지**: `content_id` 기반 단일 상태 머신 + 영구 볼륨 + idempotency key + `DRAFT_SAVED`/재열기 검증 이전 자동 재시도 금지.
4. **Work3 원본 검증**: `content_id, image_id, sha256, source_work3, order, image_count` manifest 필수; 불일치 시 업로드 중단. 임의 대체 이미지 생성/사용 금지.
5. **재열기 검증**: 제목·본문·볼드·태그·카테고리·이미지 개수/순서/해시·명함 확인 후 `draft_reopen_verified=true` 설정. `published=false` 필수.
6. **진단/테스트**: scheduler enabled/disabled, `POST /scheduler/run` 응답 본문, 저장소 상태, 실제 네이버 공개 글 목록(읽기 전용)과 임시저장 목록을 서로 대조. HTTP 상태코드만으로 성공률 계산 금지.
