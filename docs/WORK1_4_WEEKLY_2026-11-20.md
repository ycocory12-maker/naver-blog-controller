# Work1~4 주간 운영 점검 및 개선 실행서 — 2026-11-20 (KST 09:00)

## 1. 점검 범위 및 사실
- 기간: 2026-11-13 09:00 ~ 2026-11-20 09:00 한국시간.
- Railway `naver-publisher-v3` HTTP 로그: `GET /scheduler` 200 **13회**, `POST /scheduler/run` 200 **13회**. **HTTP 200은 발행 성공·임시저장 성공이 아님**.
- Railway `naver-daily-publish`: cron `0 0,6 * * *`, 최근 실행 컨테이너 시작 흔적. 운영 스케줄이 여전히 존재함.
- Publisher v3 `publish-v3/naver.js`의 `saveDraft()`는 `draft_mode_not_calibrated_use_publish` 오류를 발생시킴. `publish-v3/scheduler.js`의 `publishDue()`는 `execute()` 호출로 공개 발행 가능한 경로.
- 기존 `naver-controller-github`의 `WORK2_TRIGGER_URL`, `WORK3_TRIGGER_URL`, `PIPELINE_STATE_FILE` 변수 미설정; 볼륨 0개. 최근 7일 컨트롤러 HTTP·배포 로그는 조회 결과 0건. 정상 운영으로 추정하지 않음.
- Publisher v3에는 `/data` 볼륨이 있으나, Work1~4 컨트롤러와 동일 상태 저장소임을 의미하지 않음.
- Work1 일별 기획, Work2 법령 검수, Work3 원본 이미지 해시, Work4 네이버 임시저장 후 재열기, 실제 공개 게시물 여부는 **확인 불가**.
- 007은 사용자 지시로 제외, 032는 검증 완료 이력으로 재전송 금지. 이전 대기 순서 008→037→038→039는 현재 상태 조회 없이 재전송하지 않음.
